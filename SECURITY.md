# Security policy

If you find a security problem in Meowio (for example, a way to leak stored credentials or tokens), please report it privately through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/layton-brewer/Meowio/security/advisories/new) rather than opening a public issue.

Please never post account tokens, debrid keys, add-on URLs that contain keys, or private stream links in public issues.
